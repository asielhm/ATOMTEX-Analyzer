The subset and its generating script are provided in this repository. It selects
27 nuclides with qualifying gamma emissions from 28 considered nuclides, 20–3500
keV and emission probability per parent decay >=0.005. Cs-137 includes the
Ba-137m daughter branch. The upstream data and this subset may contain errors
and are not definitive. No upstream C++ library code is used.
